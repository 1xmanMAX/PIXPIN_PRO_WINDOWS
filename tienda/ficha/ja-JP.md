## Description

```text
PinDesk は、Windows 向けの高速でプライバシーに配慮したワークスペースです。画面上のあらゆるものをキャプチャし、ほかのウィンドウの上に浮かべておき、メモやファイル、録音・録画をチャットのように使えるプロジェクトで整理できます。

Windows のネイティブ技術（Direct2D、DirectWrite、Media Foundation）で作られているため、すぐに起動し、性能が控えめな PC でも快適に動きます。アカウントは不要で、PinDesk のクラウドもありません。プロジェクトはお使いの PC に保存されます。

キャプチャとピン留め
• 範囲、ウィンドウ、画面全体、スクロールするページをキャプチャ。GIF の録画や、Windows の OCR による文字のコピーもできます。
• ペン、矢印、枠、テキスト、モザイクですぐに注釈を追加。
• 画像、動画、PDF、メモ、タスクリストを常に最前面にピン留め。画面の一部をリアルタイムに映すライブピンも作れます。

チャットのようなプロジェクト
• プロジェクトごとにチャット形式のノートブック。メモ、説明付きの写真、ボイスメモ、文書、表、キャンバスをまとめて管理します。
• PDF、Word、EPUB、Markdown、HTML をアプリ内で閲覧し、手書きの書き込みやブックマークも可能。Office がなくても Word、Excel、PowerPoint のファイルを開けます。
• スクリーンショット内の文字も含めて、すべてを検索できます。

キャンバスと専門ビューアー
• 図形、手書き、寸法、グラフ、表、正確な作図に対応した無限キャンバス。PNG、SVG、PDF に書き出せます。
• 元のソフトがなくても、AutoCAD の DWG 図面、Revit と IFC の 3D モデル、Civil 3D の LandXML 地形を表示できます。

授業や会議の記録
• 音声、画面の動画、Web カメラの写真とクリップを一度に記録し、スクリーンショットは該当する分の位置に配置されます。
• 音声の文字起こしはお使いの PC 上で行われます。任意の TypeSafe キーを設定すると、話している間に Jev モデルが議題の項目をリアルタイムでチェックします。
• 「授業を復習」では、動画、同期した文字起こし、スクリーンショット、ブックマークを並べて表示。メモや録音を Anki カードにすることもできます。
• 記録は、アプリの異常終了や停電からも保護されます。

タスクと時間割
• 「#家 銀行に電話 10/18 17:00」のように普段の言葉でタスクを入力し、リストやカンバンボードで確認できます。
• リマインダー付きの時間割と、任意の Google カレンダー表示（読み取り専用）。
• 一日のタイムラインと、学んだ教訓の記録。

AI アシスタント（任意）
• 文書を読み、タスクやメモを作成し、キャンバスに図を描き、Web で調べることもできるアシスタントのチャット。
• ご自身の API キーで Anthropic Claude または DeepSeek を利用します。キーがなくても、ほかの機能はすべてそのまま使えます。

スマートフォンと同期
• 対応する Android アプリとローカル Wi-Fi 経由で、暗号化して、クラウドを使わずにプロジェクトを同期します。
• 記録中はスマートフォンを追加のカメラとして使えます。撮った写真は正確な分の位置に届きます。

14 言語のインターフェース。広告なし、テレメトリなし。
```
