## Description

```text
PinDesk는 빠르고 개인 정보를 지키는 Windows용 작업 공간입니다. 화면의 무엇이든 캡처해 다른 창 위에 띄워 두고, 메모와 파일, 녹음·녹화를 채팅처럼 쓰는 프로젝트로 정리하세요.

Windows 기본 기술(Direct2D, DirectWrite, Media Foundation)로 만들어져 바로 실행되고, 사양이 낮은 PC에서도 부드럽게 동작합니다. 계정이 필요 없고 PinDesk 클라우드도 없습니다. 프로젝트는 사용자의 PC에 저장됩니다.

캡처와 고정
• 영역, 창, 전체 화면 또는 스크롤 페이지를 캡처하고, GIF를 녹화하거나 Windows OCR로 텍스트를 복사하세요.
• 펜, 화살표, 상자, 텍스트, 모자이크로 바로 주석을 달 수 있습니다.
• 이미지, 동영상, PDF, 메모, 할 일 목록을 항상 맨 위에 고정하거나, 화면의 일부를 실시간으로 보여 주는 라이브 고정을 만드세요.

채팅 같은 프로젝트
• 각 프로젝트는 채팅 형식의 노트입니다. 메모, 설명이 있는 사진, 음성 메모, 문서, 표, 캔버스를 한곳에 모읍니다.
• PDF, Word, EPUB, Markdown, HTML을 앱 안에서 필기와 책갈피와 함께 읽으세요. Office 없이 Word, Excel, PowerPoint 파일을 엽니다.
• 스크린샷 속 텍스트까지 모두 검색합니다.

캔버스와 전문 뷰어
• 도형, 필기, 치수, 그래프, 표, 정밀한 작도를 지원하는 무한 캔버스. PNG, SVG, PDF로 내보낼 수 있습니다.
• 원래 프로그램 없이 AutoCAD DWG 도면, Revit 및 IFC 3D 모델, Civil 3D LandXML 지형을 볼 수 있습니다.

수업과 회의 기록
• 오디오, 화면 동영상, 웹캠 사진과 클립을 한 번에 기록하고, 스크린샷은 해당 분에 맞춰 배치됩니다.
• 음성은 사용자의 PC에서 텍스트로 변환됩니다. 선택 사항인 TypeSafe 키를 넣으면 말하는 동안 Jev 모델이 안건 주제를 실시간으로 체크합니다.
• '수업 복습'은 동영상, 동기화된 대본, 스크린샷, 책갈피를 나란히 보여 줍니다. 메모와 녹음을 Anki 카드로 만들 수도 있습니다.
• 기록은 앱 비정상 종료와 정전으로부터 보호됩니다.

할 일과 시간표
• "#집 은행에 전화 10/18 17:00"처럼 평소 말투로 할 일을 적고 목록이나 칸반 보드로 확인하세요.
• 알림이 있는 수업 시간표와 선택 사항인 Google 캘린더 보기(읽기 전용).
• 하루의 타임라인과 배운 교훈 기록.

AI 도우미(선택 사항)
• 문서를 읽고, 할 일과 메모를 만들고, 캔버스에 그림을 그리고, 웹에서 정보를 찾을 수 있는 도우미 채팅.
• 사용자 본인의 API 키로 Anthropic Claude 또는 DeepSeek를 사용합니다. 키가 없어도 나머지 기능은 그대로 작동합니다.

휴대폰과 동기화
• 함께 쓰는 Android 앱과 로컬 Wi-Fi로 프로젝트를 암호화하여 클라우드 없이 동기화합니다.
• 기록 중에 휴대폰을 추가 카메라로 사용하세요. 사진이 정확한 분에 들어갑니다.

14개 언어 인터페이스. 광고와 원격 분석(텔레메트리)이 없습니다.
```
