## Description

```text
PinDesk 是一款快速、注重隐私的 Windows 工作空间：截取屏幕上的任何内容，让它悬浮在其他窗口之上，并把笔记、文件和录音录像整理到像聊天一样的项目中。

它基于 Windows 原生技术（Direct2D、DirectWrite、Media Foundation）构建，启动即开，即使在配置一般的电脑上也运行流畅。无需账户，也没有 PinDesk 云端：你的项目始终保存在你的电脑上。

截图与置顶
• 截取区域、窗口、全屏或长网页，录制 GIF，或用 Windows OCR 复制文字。
• 立即标注：画笔、箭头、矩形框、文字和马赛克。
• 将图片、视频、PDF、笔记和任务清单置顶于所有窗口之上，或创建实时贴图，实时显示屏幕的某一区域。

像聊天一样的项目
• 每个项目都是一本聊天式笔记本：笔记、带说明的照片、语音笔记、文档、表格和画布汇集一处。
• 在应用内阅读 PDF、Word、EPUB、Markdown 和 HTML，支持手写批注和书签。无需 Office 即可打开 Word、Excel 和 PowerPoint 文件。
• 全局搜索，连截图里的文字也能搜到。

画布与专业查看器
• 无限画布：图形、手写、尺寸标注、函数图像、表格和精确作图。可导出为 PNG、SVG 或 PDF。
• 无需原软件即可查看 AutoCAD DWG 图纸、Revit 和 IFC 三维模型以及 Civil 3D 的 LandXML 地形。

录制课堂与会议
• 一次录制即可包含音频、屏幕视频、摄像头照片和短片，截图会自动放到对应的分钟。
• 语音在你自己的电脑上转写成文字。填入可选的 TypeSafe 密钥后，Jev 模型会在你讲话时实时勾选议程中的主题。
• “学习这节课”将视频、同步的文字稿、截图和你的书签并排显示。还可以把笔记和录音制作成 Anki 卡片。
• 录制内容可防止程序崩溃和意外断电造成的丢失。

任务与课表
• 用自然语言写任务（“#家 给银行打电话 10/18 17:00”），以列表或看板（Kanban）查看。
• 带提醒的课程表，以及可选的 Google 日历只读视图。
• 一天的时间线和经验教训记录。

AI 助手（可选）
• 助手聊天可以阅读你的文档、创建任务和笔记、在画布上绘图，并能查询网络。
• 使用你自己的 API 密钥接入 Anthropic Claude 或 DeepSeek。没有密钥时，其他功能照常使用。

与手机同步
• 通过本地 Wi-Fi 与配套的 Android 应用同步项目，全程加密，不经过云端。
• 录制时可把手机当作额外的摄像头：照片会准确落在对应的分钟。

界面支持 14 种语言。无广告，无遥测。
```
